# Create FTB Chunks Guard (NeoForge 1.21.1)

Server-side mod to protect FTB Chunks claims from Create and Aeronautics machinery:
- Allows Create trains to freely operate and move inside claimed chunks.
- Restricts airships/aeronautics/contraptions to owners, allies, and recent passengers/pilots (10-second grace period).
- Blocks destructive kinetic blocks (drills, pumps, pistons, bearings, saws, etc.) from operating across or inside foreign claims.
- Anti-dupe protections on container interaction and entity UUID reuse.
