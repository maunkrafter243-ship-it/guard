# Create FTB Chunks Guard (NeoForge 1.21.1)

## Сборка `.jar` файла
В этой среде нет доступа в интернет для скачивания зависимостей Minecraft/NeoForge/Create и компиляции `.jar`, поэтому подготовлен полный готовый проект.

Чтобы собрать готовый `.jar` за 1 минуту на своем ПК:
1. Убедитесь, что установлена **Java 21**.
2. Распакуйте архив и откройте терминал в папке проекта.
3. Запустите сборку (если установлен Gradle: `gradle build`, либо скопируйте `gradlew` / `gradlew.bat` / папку `gradle` из стандартного NeoForge 1.21.1 MDK и выполните `./gradlew build`).
4. Готовый серверный мод появится в папке `build/libs/createftbguard-1.0.0.jar`.
5. Поместите `.jar` в папку `mods/` сервера. При первом запуске в `config/createftbguard-server.toml` автоматически создастся конфиг.
